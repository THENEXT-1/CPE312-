วิธีใช้งาน

ทดลองโมเดลข้อมูลบ้านในแคลิฟอร์เนียได้จากหน้าเว็บ หรือเรียกใช้ผ่านบริการของคุณ

ประเมินราคา

กรอกข้อมูลย่าน 8 รายการ แล้วรับค่าประเมินจากโมเดล Random Forest ที่ฝึกด้วยข้อมูลบ้านในแคลิฟอร์เนีย

เรียกใช้ API

ส่งข้อมูล JSON ตามลำดับฟีเจอร์ไปยัง POST /predict. ตรวจสอบสถานะบริการได้ที่ GET /health.

curl -X POST http://127.0.0.1:5000/predict -H "Content-Type: application/json" -d '{"features":[8.3,25,6,1,1200,3,34.2,-118.3]}'

Invoke-RestMethod -Uri http://127.0.0.1:5000/predict -Method Post -ContentType "application/json" -Body '{"features":[8.3,25,6,1,1200,3,34.2,-118.3]}'

ลำดับฟีเจอร์: MedInc, HouseAge, AveRooms, AveBedrms, Population, AveOccup, Latitude, Longitude

ใช้งานได้ทุกที่ด้วย Docker

สร้างอิมเมจพร้อมฝึกโมเดล แล้วเปิดบริการ Flask บนเครื่องของคุณ

docker build -t ds-ml-service .
docker run --rm -p 5000:5000 ds-ml-service
